# La Demeure des Dix MCP server

Public, read-only remote MCP server for La Demeure des Dix, a privatized holiday house for 10 guests near Rouen, Normandy, France.

- Endpoint: https://demeuredesdix.fr/mcp (streamable HTTP, no authentication)
- Tools: get_property_information, get_dog_information, get_stay_rules, get_booking_options, check_availability, get_quote
- Documentation: https://demeuredesdix.fr/llms.txt
- Official MCP registry: io.github.Wakinah-Entreprise/demeuredesdix
- Website: https://demeuredesdix.fr
- Contact: bonjour@demeuredesdix.fr

This repository only holds the listing metadata. The server is hosted; no code is published here.
